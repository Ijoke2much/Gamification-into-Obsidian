# Temporary UI previews

Static HTML mocks for experimenting with layouts **outside** Obsidian.

## Pixel boss battle

- **File:** `pixel-boss-battle-preview.html`
- **Open in browser (default app):** from plugin root run  
  `npm run preview:pixel-boss`
- **Better font loading (Google Fonts):** run  
  `npm run preview:pixel-boss:serve`  
  then open **http://localhost:4177/pixel-boss-battle-preview.html**

Delete this folder anytime; it is not part of the built plugin.
